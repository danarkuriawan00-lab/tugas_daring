Kode Google Apps Script (Copy & Paste) 
function doPost(e) {
  try {
    var spreadsheet = SpreadsheetApp.openById("18uQ6eXOYGkDYy-Z_JwDGkjf9LYwpMlHLCtWt5G35vtw");
    var sheet = spreadsheet.getSheets()[0];
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.waktuSelesai,
      data.nama,
      data.kelas,
      data.noAbsen,
      data.tanggalLahir,
      data.mapel,
      data.nilai,
      data.ringkasan
    ]);
    return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
  } catch (error) {
    return ContentService.createTextOutput("Error: " + error.message).setMimeType(ContentService.MimeType.TEXT);
  }
}

*Gunakan ID spreadsheet di kode dan pastikan Web App pada URL bawaan di atas sudah memakai ID tersebut. Deploy sebagai versi baru dengan Execute as: Me dan Who has access: Anyone, agar siswa dengan akun/profil Chrome berbeda tetap dapat mengirim hasil ke spreadsheet yang sama. URL kustom yang disimpan melalui pengaturan hanya berlaku pada browser tersebut.
